# Conversation Archive Topic Taxonomy

Status: active
Last updated: 2026-06-05

## Primary Topics

Each archived conversation gets exactly one primary topic.

Allowed values:

- `pipeline_runtime_and_fusion`
- `onboarding_and_game_packs`
- `review_calibration_and_replay`
- `research_agent_and_packets`
- `operator_workflows_and_automation`
- `publishing_lineage_and_metrics`
- `misc_project_admin`

## Routing Intent

Use:

- `pipeline_runtime_and_fusion`
  - runtime signals
  - ROI/template work
  - fusion behavior
- `onboarding_and_game_packs`
  - pack manifests
  - onboarding drafts
  - game-pack structure
- `review_calibration_and_replay`
  - review sessions
  - calibration
  - replay
  - comparison tooling
- `research_agent_and_packets`
  - researcher packets
  - handoffs
  - custom GPT research behavior
- `operator_workflows_and_automation`
  - dashboard
  - backlog
  - automations
  - conversation archival
  - Codex workflow policy
- `publishing_lineage_and_metrics`
  - post ledgers
  - posted metrics
  - export lineage
  - downstream analytics
- `misc_project_admin`
  - anything still useful but not strong enough for another primary bucket

## Secondary Tags

Secondary tags are optional and may include any additional topic categories that help later lookup.

Secondary tags do not change the rule that each conversation belongs to exactly one primary topic batch.
