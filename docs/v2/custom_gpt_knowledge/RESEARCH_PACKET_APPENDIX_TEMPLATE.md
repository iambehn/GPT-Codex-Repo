# Research Packet Appendix Template

Use this template only as a supporting appendix to a decision-ready packet.

This file is the upload-ready template for the routed support artifact `packet_appendix`.

Do not use it as the primary handoff when the work is meant to change the repo.

## Allowed Uses

- overflow evidence
- long source excerpts
- extra screenshots or crops
- secondary examples
- secondary negative examples

## Disallowed Uses

- replacing the packet recommendation
- replacing the packet acceptance target
- hiding the real next action inside supporting material
- acting like a broad research memo

## Template

```text
appendix_id:
related_packet_id:
purpose:
primary_decision_target:

supporting_evidence:
  - evidence_id:
    path_or_url:
    timestamp:
    description:
    why_it_matters:

secondary_examples:
  - short labeled example

negative_examples:
  - short labeled example

source_excerpts:
  - keep only what is needed to support the packet

operator_notes:
  - any short handling notes that do not change the packet recommendation
```

## Rule

If Codex would still need to ask “what should I do next?”, this should have been a packet, not an appendix.
